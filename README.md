# Nigeria Poverty Intelligence
Nigeria in Data — Beyond the Numbers | Project 01

Exploratory independent research by Christian Somtoo Obiechina. Analysis of 4,715 households in Nigeria's 2023–24 GHS Panel, with historical comparisons and conditional welfare scenarios.

## Findings
Person-weighted poverty below $3/day (2021 PPP): 48.29%; rural 57.60%; urban 31.22%. These are survey estimates, not current official poverty rates. The conditional 2026 scenario is not an independently validated forecast.

## Reproduction
Obtain authorized Wave 5 CSV and Stata archives from https://microdata.worldbank.org/catalog/6410 and place them beside nigeria_poverty_analysis.py. Install numpy and pandas, then run python nigeria_poverty_analysis.py. Do not commit microdata.

See DECLARATIONS.md and VALIDATION.md. This initial public release contains the baseline analysis and selected aggregate results; the remaining model scripts and manuscript are not yet deployed. Not peer reviewed.
